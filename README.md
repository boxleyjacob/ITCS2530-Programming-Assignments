About This Repository

This repository serves as the central hub for all programming assignments completed in ITCS 2530. Each project demonstrates core C++ concepts including variables, control flow, functions, arrays, and object-oriented programming, developed throughout the course.

About Me
My passion lies in comprehending complex analytics within basketball — not just understanding how players impact the game, but measuring the magnitude of that impact and how it shapes team performance when specific players are on or off the court relative to others.
I am particularly interested in advanced metrics that go beyond traditional box score statistics, using data to build a full spectrum of player performance across categories such as scoring, playmaking, defending, rebounding, and overall impact.
My long-term goal is to develop a program capable of differentiating players based on these advanced analytics, compiling a comprehensive performance spectrum that ranks players from elite to below average across multiple dimensions. This intersection of data analysis and basketball is what drives my interest in programming and motivates me to build real, meaningful software.
